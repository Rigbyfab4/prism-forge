# prism-toggle

A Claude Code desktop mod: a one-row PRISM on/off switch above the prompt, plus `/prism [on|off|status]`.
It drives the CLI in this repo (`prism-forge status`, `enable`, `disable`) and parses the first line of
`status` output, so change that wording only together with `hooks/register.tsx`.

- `hooks/register.tsx` the mod; `tests/prism.test.tsx` its tests (run with the plugin test runner, not `npm test`)
- `types/index.d.ts` the mod's own state types
- `.claude-plugin/types/` is generated by the app and ignores itself; it is not committed

## Setup (Windows defaults)

Point the app at this folder, for example in `~/.claude/settings.json`:

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "C:\path\to\prism-forge\mods\prism-toggle" } }
```

The mod needs `node.exe` and this repo's `bin/prism-forge.js`. The defaults (`CONFIG` at the top of
`hooks/register.tsx`) are Windows paths: `C:\Program Files\nodejs\node.exe` and
`Git_Repos\prism-forge\bin\prism-forge.js` under your home folder. Override them with the plugin's
`node` and `cliFromHome` options instead of editing the file.

Turning PRISM off or on applies to the next message; start a new session for the full effect.
